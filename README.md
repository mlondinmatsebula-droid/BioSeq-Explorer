# BioSeq-Explorer

A Python toolkit for DNA sequence analysis: GC content, transcription, reverse complement, translation, ORF finding, mutation detection, and statistics.

## Features
- Load/save FASTA
- GC%, AT%, base frequencies
- DNA → RNA transcription
- Reverse complement
- Translation with codon table
- ORF finder (all frames)
- Mutation detection (SNPs, indels)
- Summary statistics

## Usage
```bash
python main.py data/sample_genes.fasta
